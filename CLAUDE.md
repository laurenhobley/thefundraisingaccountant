# fac.prompt.builder

## Project rules

These three rules matter most. Follow them in every session.

1. **Plan before code.** Before writing any code, ask the user questions and propose a plan. Wait for the user to approve the plan before building.
2. **Never invent numbers.** A number appears on the sheet only if the member typed it or accepted it from their own document. No placeholder, example, default, estimated, or AI-generated figures.
3. **Never put a secret key in the web page.** Anyone can see what is in a web page. API keys and tokens stay server-side (e.g. in a `.env` file, which `.gitignore` excludes), never in HTML, front-end JavaScript, or anything sent to the browser.

## Environment

- Windows. The project lives on an external Seagate drive (`D:`), which must be plugged in to work on it.
